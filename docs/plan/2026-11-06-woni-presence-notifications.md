# 하던일 원이 표시와 답변 알림

목표: 원이 진입점을 쉽게 찾고 새 답변을 화면과 기존 기기 알림에서 확인한다.

- `web/index.html`, `web/style.css`: 원이 버튼에 명확한 이름·아이콘·새 답변 배지를 추가한다. 기존 헤더와 모바일 폭을 유지한다.
- `web/woni.js`, `web/app.js`: 인증된 보드에서 팝업이 닫혀도 원이 상태를 확인하고 새 답변을 배지와 안내로 표시한다. 첫 조회를 기준으로 삼고, 읽은 답변은 반복 표시하지 않는다. 알림 클릭은 해당 대화로 연다.
- `push.py`, `server.py`, `web/sw.js`: 기존 구독 기기에 원이 답변의 빈 푸시 신호를 보내고 내용은 보드에서 읽는다. 원이 연결 실패는 기존 세션 알림을 막지 않는다. 재시작·재시도 시 중복과 과거 답변의 소급 알림을 막는다.
- `tests/test_woni_frontend.cjs`, `tests/test_push.py`, `tests/test_frontend.cjs`: 기준선, 답변 도착, 중복 방지, 잠금, 알림 이동과 연결 실패를 합성 데이터로 확인한다. 운영 대화에 메시지를 보내지 않는다.
- 테스트와 변경 범위 sloplint를 수행한 뒤 기존 세션을 보존하는 배포 절차로 운영 반영 및 읽기 검증한다.
