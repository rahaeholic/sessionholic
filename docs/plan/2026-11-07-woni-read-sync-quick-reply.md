# 하던일 원이 읽음 공유와 추천 답장

목표: 원이 앱에서 확인한 답변이 하던일 원이 배지에 다시 남지 않게 하고, 원이 답변의 추천 답장(👉)을 눌러 바로 보낸다.

- `woni_bridge.py`: 원이 상태의 `readThrough`(이 시각까지 끝난 답변은 읽음)를 그대로 전달하고, 읽음 기록(`read`)만 좁게 검증해 원이 `/v1/read`로 보낸다.
- `server.py`: 기존 인증·CSRF를 거치는 `POST /api/woni/read`를 연결한다.
- `web/woni.js`: 읽음 기준이 있으면 그보다 늦게 끝난 완료 답변만 배지에 센다. 대화 화면이 보이면 보인 답변까지 기록하고, 흐름 필터로 가린 안 읽은 답변 앞에서는 멈춘다. 기준이 없는 이전 원이에서는 기존 탭별 기준선을 유지한다.
- `web/woni.js`, `web/style.css`: 가장 최근 답변의 👉 줄을 최대 2개의 버튼으로 바꾸고 누르면 같은 요청 ID 규칙으로 새 메시지를 보낸다. 작성 중인 초안·첨부·답글 대상은 건드리지 않는다. 👉·🔊 줄은 본문에서 숨긴다.
- `tests/test_woni_bridge.py`, `tests/test_woni_frontend.cjs`: 합성 데이터로 전달·검증, 다른 기기에서 읽은 답변 제외, 기록 1회, 추천 답장 전송을 확인한다.
