# 큰 글자와 모바일 상단

글자 크기를 두 단계 늘리고, 모바일에서 분할 추가와 하던일 설정을 잘림 없이 바로 사용한다.

- 웹 `app.js`, `theme-init.js`, `index.html`, `style.css`: 기존 선택에 137.5%·150%를 추가하고 저장/초기 표시를 맞춘다. 설정 선택지는 폭에 맞춰 줄바꿈한다. 모바일 상단도 줄바꿈과 새로고침 아이콘으로 넘침을 막는다. `workspace.css`의 모바일 분할 화면에서도 설정을 유지한다. PC 배치는 유지한다.
- 웹 설정 버튼은 곧바로 하던일 설정을 열고, 세션 메뉴와 Android `BoardScreen.kt` 상단의 라이언원 설정 진입은 제거한다. 목록의 앱 제목은 유지하며 설정 아이콘은 웹 상단에 하나만 남긴다. `MainActivity.kt`의 불필요한 앱 설정 콜백을 제거하고, 이전 웹의 설정 연결도 웹 설정으로 안내한다. 기존 출처 검사·WebView·초안·전체 화면 전환을 유지한다.
- 기존 Node 검사에서 새 크기 선택/저장/초기 표시와 설정 진입을 확인한다. 격리 브라우저에서 320·390px의 기존/최대 글자, 목록/분할/대화의 버튼 경계와 초안·새로고침 후 설정 보존을 검사한다. Android 기존 오프라인 통합 검사에 웹 설정 진입·복귀를 반영한다.
- 단위/통합 검사와 sloplint 후 기존 웹 배포 및 서명 앱 업데이트 경로로 게시하고 제공 파일의 해시를 확인한다. 새 의존성·삭제·실제 사용자 메시지 전송은 없다.
