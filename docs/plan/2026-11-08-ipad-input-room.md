# 아이패드 입력 영역 높이

목표: 하드웨어 키보드의 하단 보조 막대 공간을 입력 전부터 확보해 채팅 높이가 포커스마다 바뀌지 않고, 터미널 끝이 잘리지 않게 한다.

원인 가설: `viewportHeight()`가 포커스 전에는 전체 높이, 포커스 후에는 줄어든 높이를 사용한다. `app-shifted`의 transform이 앱과 그 안에 들어간 터미널에 중복 적용된다.

- `web/app.js`: 기존 iPad 표시와 키보드 높이 계산을 재사용한다. 최상위 iPad 화면에서 기본 55px(기존 보조 막대 회귀 조건)을 미리 확보하고 실제 작은 inset이 더 크면 세션 동안 그 높이를 유지한다. 가상 키보드·확대·회전·분할 iframe에서는 공간을 중복 차감하지 않는다.
- `web/style.css`: 앱 내부 터미널에는 부모 위치 보정만 적용한다. 독립/나란히 터미널은 기존 보정을 유지한다.
- `tests/test_frontend.cjs`: 포커스·blur·입력창 교체, 작은 inset 학습, 가상 키보드와 콘텐츠 리사이즈, 줌·PC·Android·iframe 제외를 검사한다. 격리 브라우저에서 보정 전후 실제 터미널/입력창 경계를 비교한다.
- `docs/verification.md`: 실제 확인한 결과와 실기 미검증 범위를 기록한다.

실행: 회귀 실패 확인 → 최소 구현 → 관련 Node 검사와 격리 브라우저 화면 검수/sloplint → 개인 원격 커밋·기존 웹 정적 파일만 백업 후 배포·운영 해시 확인. 실제 사용자 세션에는 입력하거나 포커스를 변경하지 않는다.
