# 대화 안의 세션 메뉴

목표: 실제 터미널/채팅 화면 상단의 메뉴 버튼에서 목록 카드와 같은 세션 동작을 사용한다.

수정 순서와 파일:
1. `web/app.js`: `cardActions`를 공유하는 메뉴 열기 함수를 만들고 `drawDetail` 헤더에 ‘세션 메뉴’ 버튼을 추가한다. 클릭 시 해당 문서가 실제로 보고 있는 최신 세션 신원을 확인한다. 메뉴 열기는 입력·첨부·음성 상태나 실행을 변경하지 않는다. 집중모드와 터미널/채팅 보기 모두 같은 헤더를 사용한다.
2. `web/workspace.js`: 자식 창에서도 기존 ‘다른 창에서 보기’ 동작을 부모의 분할 관리자로 요청할 수 있도록 소유권을 검사해 연결한다. 이미 열린 세션 중복 방지·최대 창 수·실행 생성 금지 정책은 유지한다.
3. `web/style.css`: 메뉴 버튼의 터치 영역·시각적 크기를 헤더의 기존 버튼과 통일한다. PC는 버튼 옆 팝오버, 작은 화면은 기존 바텀시트를 재사용한다.
4. `tests/test_frontend.cjs`, `tests/test_workspace.cjs`: 목록/대화 메뉴의 동작 목록 일치, 다른 분할창 대상 유지, 오래된 헤더·로그아웃 거부, 초안·조합 보존, 자식 창 소유권을 검증한다. 실제 실행 종료·삭제·전송은 테스트하지 않는다.
5. `README.md`, `scripts/public-files.json`: 새 진입점을 안내하고 계획 파일을 등록한다. 서버·실행 API는 수정하지 않는다.

검증: 관련 테스트와 전체 JS·공개 파일 감사·diff 검사 → 격리 canary → 한 번의 배포 → 제공 파일·기존 터미널·설정 보존 확인. 실제 브라우저 검증은 승인된 개인 Chrome 연결이 있을 때 수행하며, 소스/fixture 확인과 구분해 보고한다.
