# 후속 개선 — 순차 구현, 한 번 배포

목표: 기존 작업을 보존하면서 PC 장시간 복귀를 관찰하고, 실제 화면 검수·Mac 관측 만료·하위 결과·결과 근거·작업 위임을 순서대로 개선한다. 기준은 c5c0605이며 중간 운영 배포는 하지 않는다.

1. PC 연결: scripts/session_soak.py와 테스트를 추가한다. 인증값·본문 없이 12~24시간의 host/terminal/복귀 변화를 비공개 파일에 남긴다. 목록에서 사라짐과 실제 종료를 구분하며 native 입력/종료는 하지 않는다. 임시 HTTP 서버에서 단절·목록 누락·복귀·다른 ID·로그 권한을 검증한다. 실제 프로세스 생존이 확인되기 전에는 새 Windows 실행 서비스를 설치하지 않는다. 운영 시험은 최종 배포 후 시작하고 경과 시간만 보고한다.
2. 화면 검수: 지정 개인 Chrome에서 현재 연결을 확인하고 로컬 화면으로 채팅/터미널·한글 조합·초안·스크롤을 검사한다. 공식 연결 실패는 범위와 오류를 기록하며 다른 프로필로 우회하지 않는다. 발견한 재현 가능한 문제만 수정한다. 최종 운영 화면은 배포 후 별도 확인한다.
3. Mac 실행 관측: collector.py에 어댑터별 실제 수집 세대를 추가한다. heartbeat는 확인으로 사용하지 않는다. server.py Board의 poll/apply_live와 SnapshotResponses에 관측 revision을 분리하고, chat.py의 실제 읽기에도 기존 RuntimeObservations를 적용한다. FE는 기존 만료/lastKnown 경로를 재사용한다. 캐시·오류·같은 토큰·구버전 watcher가 lease를 갱신하지 않는지, 실제 수집 갱신이 불필요한 SSE/GET을 만들지 않는지 테스트한다.
4. 하위 결과: web/app.js 관계 패널에서 명시적으로 연결된 자식 하나를 펼쳤을 때만 /api/chat/state로 읽고 session_context.js를 재사용한다. 최대 2개 조회, 선택·인증·conversation 세대 확인, 상태·마지막 저장 답변·응답 시각과 원문 이동을 제공한다. 완료 시각을 모델 응답 시각으로 단정하지 않는다. 자동 입력/재개는 없다.
5. 결과 근거: web/session_context.js에서 마지막 저장 답변의 명시 Markdown 링크만 제한적으로 추출한다. http(s) 외 실행 스킴을 차단하고 로컬 경로는 원문 위치로 안내한다. 결과물 링크와 테스트/검증 발췌는 원문 근거로 표시하며 통과·목표 완료를 추정하지 않는다. UI·순수 함수 테스트를 추가한다.
6. 작업 위임: 현재 작업의 네이티브 하위 에이전트에 리뷰/조사/검증을 요청하는 제한된 대화창을 추가한다. 요청 내용·전달할 발췌·원본 수정 요청 여부·완료 기준을 사용자에게 보여 주고 명시 전송한다. 기존 Chat.send의 정확한 대상 및 영수증을 재사용한다. 지원하지 않는 CLI에서 하위 실행을 가장하지 않도록 요청문에 중단/설명 조건을 넣는다. 별도 실행 서버·계정 전환·자동 모델 호출은 추가하지 않는다. 초안·첨부를 보존하고 인증/선택 전환·중복 클릭·응답 유실을 검증한다.

변경 지도: collector.py, server.py, chat.py, runtime_observation.py(필요한 근거 종류), web/app.js, web/session_context.js, web/index.html, web/style.css, 새 scripts/session_soak.py 및 관련 tests, scripts/public-files.json, docs/verification.md. 기존 원본·인증·목표/봇 저장소는 마이그레이션하지 않는다.

검증: 단계별 관련 Python/Node 테스트 → 전체 unittest/Node 및 공개 검사 → 불변 commit/배포 archive → 복사 상태 canary → 한 번의 운영 교체 → HTTPS 자산·SSE·계정/설정·기존 살아 있는 터미널 보존 확인 → 지정 브라우저 검수와 PC 관찰 시작. 12~24시간 시험은 실제 경과 전에 성공으로 기록하지 않는다. 실패 시 원장과 원본 기록을 유지하고 해당 기능만 차단한다.
