# 모바일 뒤로 가기 공통 처리

목표: 모바일에서 시스템 뒤로 가기는 열린 대화상자부터 닫고 직전 화면으로 이동하며 최상위에서는 연속 두 번일 때만 앱 밖으로 나간다.

- `web/app.js`: 모바일 최상위에 기록 보호 지점을 두고, 공통 popstate에서 최상위 대화상자의 기존 cancel/닫기 동작을 우선한다. 이미 닫힌 시트·취소가 거절된 시트·중첩 창, 대화와 터미널 기록 및 초안을 보존한다. 최상위에서 첫 뒤로 가기는 안내하고 일정 시간이 지나면 보호 지점을 복원한다.
- `tests/test_frontend.cjs`: 실제 기록 이동을 모사하여 원이 및 일반/중첩 시트, 취소 거절, 상세→목록, 최상위 2회, 시간 초과, 모달을 닫은 뒤 이동 및 기존 기록 호환성을 확인한다.
- `docs/limitations.md`: 지원 범위와 모바일 브라우저·키보드의 시스템 뒤로 가기 제한을 기술한다.
- 라이언원 `BoardScreen`: WebView의 방문 기록이 JavaScript에서 바뀌는 경우를 위해 뒤로 가기 시점에 `canGoBack()`을 직접 확인한다. 기록을 다 쓴 뒤에는 기존 원이 대화로 돌아간다.
- 원이 전용 기능이나 타 기기 인증을 변경하지 않는다. 기존 프런트엔드 전체 테스트와 가능한 격리 브라우저 시험 뒤 운영 배포를 확인한다.
